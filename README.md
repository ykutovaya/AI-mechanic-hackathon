# Цифровой механик

Проект для хакатона «ИИкузница» по кейсу компании «НейроДВС». Веб-агент объясняет результаты ML-диагностики двигателя, отвечает по руководствам и отправляет подтверждённые заявки в тестовую ТОиР. [Краткое описание задачи](documents/task.md)

## Запуск

**Онлайн.** Откройте [стенд в Yandex Cloud](https://ai-mechanic.duckdns.org/).

Для локального запуска выполните [первичную настройку](documents/setup.md) и [подготовьте индекс](documents/knowledge-base.md). Запустите из корня проекта.

**Windows**

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\start_local.py
```

**Ubuntu**

```bash
.venv/bin/python -X utf8 scripts/start_local.py
```

Откройте [локальный чат](http://127.0.0.1:8765/). Для завершения сеанса нажмите `Ctrl+C` в терминале запуска.

## Пример

Выберите машину `H275AA47` и спросите «Какое моторное масло использовать в двигателе?». Чат приведёт марки и вязкость масла со ссылкой на физическую страницу 9 руководства. Для диагностики выберите проверку `S-0139`.
